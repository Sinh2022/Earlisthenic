# Accessibility Statement

Earlisthenic is dedicated to providing an accessible, inclusive platform for audio engineers, producers, and musicians of all backgrounds.

## Key Accessibility Features

- **Keyboard Navigation:** Every module, interactive control, transport button, and answer option can be fully operated using standard keyboard controls (`Tab`, `Enter`, `Space`, `Arrow Keys`).
- **Acoustic & Hearing Protection:** All exercises incorporate peak level guards, master trim attenuators, and click-free audio fades to protect user hearing during intensive listening sessions.
- **Color Contrast & Theme Adaptation:** The interface adheres to high-contrast guidelines across Dark, Light, and Washi themes. Essential status cues do not rely on color alone and include accompanying textual labels.
- **Screen Reader Readiness:** Semantic HTML5 landmarks, ARIA labels, and live regions provide assistive technologies with accurate real-time context.
