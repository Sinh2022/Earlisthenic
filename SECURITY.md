# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 2.10.x | Yes |
| < 2.10 | No |

## Reporting a Security Issue

To report a vulnerability in Earlisthenic, please email:

**4wards.music@gmail.com**

Please provide:
1. Affected module (Audio Engine, Storage, Authentication, UI)
2. Steps to reproduce the issue
3. Potential impact

All security reports will be acknowledged within 48 hours. Please refrain from filing public issues for unpatched vulnerabilities.
